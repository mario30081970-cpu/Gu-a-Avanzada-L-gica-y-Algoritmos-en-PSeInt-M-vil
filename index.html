📋 Módulo 1 — Menús Interactivos con Segun

Un menú permite al usuario elegir entre varias opciones. Se implementa con un bucle principal (normalmente Repetir o Mientras) y la estructura Segun para ejecutar la acción correspondiente.

💡 Estructura típica
  1. Mostrar las opciones al usuario.
  2. Leer la opción elegida.
  3. Usar Segun para ejecutar el bloque adecuado.
  4. Repetir hasta que el usuario elija "Salir".

Ejercicio: Menú con opciones (Cargar, Mostrar, Salir)

// Menú interactivo con Segun
Algoritmo MenuPrincipal
    Definir opcion Como Entero
    Definir dato Como Cadena
    dato <- ""
    
    Repetir
        Escribir "=== MENÚ ==="
        Escribir "1. Cargar dato"
        Escribir "2. Mostrar dato"
        Escribir "3. Salir"
        Escribir "Elija una opción:"
        Leer opcion
        
        Segun opcion Hacer
            1:
                Escribir "Ingrese un dato:"
                Leer dato
                Escribir "Dato cargado correctamente."
            2:
                Si dato <> "" Entonces
                    Escribir "El dato almacenado es: ", dato
                Sino
                    Escribir "No hay ningún dato cargado."
                FinSi
            3:
                Escribir "¡Hasta luego!"
            De Otro Modo:
                Escribir "Opción inválida. Reintente."
        FinSegun
    Hasta Que opcion = 3
FinAlgoritmo

🔧 Probá las opciones 1, 2 y 3. El menú se repite hasta que elijas Salir.

📊 Módulo 2 — Matrices (Arreglos Bidimensionales)

Una matriz es un arreglo de dos dimensiones: filas y columnas. Se declara con Dimension indicando ambos tamaños, por ejemplo Dimension tabla[4,4]. Para recorrerla se usan bucles anidados: uno para las filas y otro para las columnas.

💡 Visualización Imaginá una tabla con 4 filas y 4 columnas. Cada celda se accede con tabla[fila, columna]. Los índices comienzan en 0 (en móvil).

Ejercicio: Cargar y recorrer una matriz 4×4 (base 0)

// Carga y recorrido de una matriz 4x4 (base 0)
Algoritmo MatrizEjemplo
    Definir tabla Como Entero
    Definir f, c Como Entero
    Dimension tabla[4,4]
    
    // Carga de la matriz
    Para f <- 0 Hasta 3 Hacer
        Para c <- 0 Hasta 3 Hacer
            Escribir "Ingrese valor para tabla[", f, ",", c, "]:"
            Leer tabla[f,c]
        FinPara
    FinPara
    
    // Mostrar la matriz (usando una variable para armar cada fila)
    Escribir "Contenido de la matriz:"
    Para f <- 0 Hasta 3 Hacer
        Definir fila Como Cadena
        fila <- ""
        Para c <- 0 Hasta 3 Hacer
            fila <- fila + " " + ConvertirATexto(tabla[f,c]) + " "
        FinPara
        Escribir fila
    FinPara
FinAlgoritmo

🔧 Observá los bucles anidados desde 0. La salida se arma concatenando en una cadena para evitar Sin Saltar.

🔎 Módulo 3 — Búsqueda Secuencial Modularizada

La búsqueda secuencial recorre un arreglo elemento por elemento hasta encontrar el valor buscado o llegar al final. Se puede implementar en una Funcion que devuelva la posición encontrada o un valor especial (ej. -1) si no existe.

✅ Reglas para PSeInt móvil
  • Usar Funcion, no SubProceso.
  • La variable de retorno se asigna directamente; no usar Retornar.
  • Los índices de los arreglos comienzan en 0.
  • NO declarar el parámetro vector dentro de la función.

Ejercicio: Buscar un valor en un vector (base 0)

// Búsqueda secuencial en un vector (base 0)
Funcion pos <- BuscarValor(vector, n, buscado)
    Definir i Como Entero
    pos <- -1   // -1 indica "no encontrado"
    Para i <- 0 Hasta n-1 Hacer
        Si vector[i] = buscado Entonces
            pos <- i
            i <- n   // Salir del bucle
        FinSi
    FinPara
    // 'pos' contiene la posición o -1, se devuelve automáticamente
FinFuncion

Algoritmo PruebaBusqueda
    Definir datos Como Entero
    Definir i, valor, resultado Como Entero
    Dimension datos[5]   // índices 0 a 4
    
    // Cargar el vector
    Para i <- 0 Hasta 4 Hacer
        Escribir "Ingrese dato ", i+1, ":"
        Leer datos[i]
    FinPara
    
    Escribir "Ingrese el valor a buscar:"
    Leer valor
    
    resultado <- BuscarValor(datos, 5, valor)
    Si resultado <> -1 Entonces
        Escribir "El valor ", valor, " se encuentra en la posición ", resultado
    Sino
        Escribir "Valor no encontrado."
    FinSi
FinAlgoritmo

La función devuelve la posición (0..n-1) o -1. Todo con base 0.

DESAFÍO INTEGRADOR Nivel 2

Sistema de Control de Stock y Ventas

Una tienda necesita un programa que administre el stock de 3 productos en 4 sucursales. Cada sucursal tiene una cantidad de cada producto. El sistema debe permitir:

  1. Cargar el stock inicial (matriz de 4×3).
  2. Vender un producto en una sucursal (restar cantidad, validando que haya stock suficiente).
  3. Reponer stock (sumar cantidad).
  4. Mostrar el stock completo (tabla).
  5. Buscar un producto en todas las sucursales (usar la función de búsqueda).
  6. Salir del programa.

📋 Requisitos técnicos (base 0)

  • Usar Funcion para las operaciones.
  • Menú principal con Segun.
  • Matriz de Dimension stock[4,3] (4 sucursales, 3 productos) con índices 0..3 y 0..2.
  • Función BuscarProducto(stock, producto) que devuelva la sucursal con mayor cantidad (o -1 si no hay).
  • Validar que las cantidades no sean negativas al vender.
